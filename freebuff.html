Freebuff

Five free AI products for coding, building, and research across CLI, desktop, web, cloud, and chat.

Why start here?
Freebuff is the free option covered by this guide. No subscription, credits, or API key are required for the included Freebuff products, though access and limits can vary.
What “free” means here
Freebuff has its own products and model catalog. It is not a free version of Claude Code, Codex, or Hermes. Freebuff Desktop can also run locally installed Claude Code and Codex when you already have the required provider access.

What it is and what it does

Freebuff brings specialized agents and model choices to your terminal, desktop, browser, and GitHub repositories. The CLI can inspect a project, make changes, and run relevant checks. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

Choose the Freebuff product that matches your task. The CLI is the simplest path for local coding.

CLI

npm install -g freebuff

Then open your project and run freebuff.

Desktop

Download Freebuff Desktop for macOS, Windows, or Linux from the official site. It supports local parallel agents.

Web, Cloud, Chat

Use Web for app building, Cloud for GitHub repositories, or Chat for research and general work.

Official source: Open Freebuff repository ↗

First time setup

  1. Install the CLI or choose Desktop, Web, Cloud, or Chat.
  2. For the CLI, change into your project directory and run freebuff.
  3. Check Git status before permitting changes.
  4. Start with one focused task and review the resulting diff.

Run in a project folder

  1. Change into the repository root.
  2. Run freebuff.
  3. Describe one focused outcome and let the agent inspect the relevant files.
Good first task: Ask for a project overview and proposed approach before requesting edits.

Copy ready prompts

Replace bracketed details with your goal, constraints, or error message.

01 · Explore

Explore this repo and summarize its architecture and checks. Do not edit.

02 · Debug

Find the cause of [bug] and explain it before fixing it.

03 · Build

Implement [feature] using the existing architecture. Ask before dependencies.

04 · Review

Review the current changes for edge cases and security issues. Do not edit.

05 · Test

Add focused tests for [behavior] and run them.

06 · Refine

Explain [module] and suggest an improvement without editing.

07 · Diagnose

Diagnose [command/error], fix the root cause, and report verification.

08 · Document

Update the README from verified code behavior and flag unknowns.

Common errors and fixes

freebuff not found

Restart the terminal and check that the global npm binary directory is on PATH.

Install fails

Check your Node.js and npm installation, registry access, and network configuration.

Wrong product for the task

Use CLI for local terminal work, Desktop for local parallel agents, Cloud for GitHub repositories, Web for app building, or Chat for research.

Files missing

Confirm the project root and make sure the relevant files are available to the selected product.

Tips for best results

  • Choose the right product.
  • Checkpoint with Git.
  • Define success criteria.
  • Inspect diffs.
  • Review current product and privacy terms.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow up.
