Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.

What it is and what it does

Freebuff offers CLI, desktop, web, and cloud products. Its CLI uses the current project directory to inspect, edit, and verify code. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

Choose your operating system. Follow the official source if an install command changes.

Windows

Install current Node.js/npm; see Windows notes or use WSL/Desktop for shell issues.

npm install -g freebuff

Mac

Install Node.js and npm using official installer or package manager.

npm install -g freebuff

Linux

Install Node.js and npm using your distribution’s instructions.

npm install -g freebuff

Official instructions: Open Freebuff documentation ↗

First-time setup

  1. Run freebuff and follow onboarding

Run in a project folder

Common errors and fixes

freebuff not found

restart terminal; check Node/npm/global PATH.

Download fails

check registry/network/proxy.

Windows execution issue

see official notes; confirm Git Bash or use WSL/Desktop.

Files missing

confirm repo root and ignore settings.

Tips for best results

  • Choose the right product
  • checkpoint with Git
  • define criteria
  • inspect diffs
  • review current privacy terms.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow-up.
