OpenAI Codex

A local coding agent in the terminal, app, and supported editors. Codex can inspect repositories, edit files, and run commands with approval controls.

Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.

What it is and what it does

A local coding agent in the terminal, app, and supported editors. Codex can inspect repositories, edit files, and run commands with approval controls. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

Choose your operating system. Follow the official source if an install command changes.

Windows

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

npm install -g @openai/codex

Mac

curl -fsSL https://chatgpt.com/codex/install.sh | sh

brew install --cask codex

Linux

curl -fsSL https://chatgpt.com/codex/install.sh | sh

npm install -g @openai/codex

Official instructions: Open OpenAI documentation ↗

First-time setup

  1. Sign in with ChatGPT or configure API access
  2. review approval and sandbox settings
  3. add AGENTS.md with project conventions.

Run in a project folder

  1. Change into the repo root
  2. check git status
  3. run codex and begin with a read-only overview.
Good first task: Ask for a read-only project overview before requesting edits.

Copy-ready prompts

Replace bracketed details with your goal, constraints, or error message.

01 · Explore

Explain this repo and how to run it. Do not edit.

02 · Debug

Investigate [bug], explain its cause, then fix minimally.

03 · Build

Implement [feature]; ask before dependencies.

04 · Review

Review my diff for bugs/security. Do not edit.

05 · Test

Add tests for [behavior] and run focused tests.

06 · Refine

Refactor [module] for [goal], preserving behavior.

07 · Diagnose

Diagnose [command/error] and fix its root cause.

08 · Document

Update docs for [feature] using verified behavior.

Common errors and fixes

codex not found

restart terminal and check PATH.

Sign-in failure

confirm browser auth, account and network.

Action blocked

review approval and sandbox request.

Too many edits

interrupt and narrow task.

Tips for best results

  • Commit first
  • request a plan
  • define success criteria
  • inspect diffs
  • verify checks.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow-up.
