Nous Research · PRACTICAL GUIDE

Hermes Agent

An autonomous agent from Nous Research with coding tools, multiple model providers, skills, memory, gateways, and desktop support.

Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.
Where Freebuff fits
Freebuff is a separate free AI coding platform. It does not provide Hermes as a free mode. Use Hermes through its own supported providers and setup.

What it is and what it does

Hermes is an autonomous agent that can work with coding tools, models from different providers, skills, memory, browser tools, and messaging gateways. It can run locally or on remote infrastructure. Treat tools and credentials as explicit capabilities and enable only what you need.

Install

The official desktop installer is recommended for macOS and Windows. CLI only installs are also available.

Windows

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Native PowerShell install. WSL2 is also supported.

macOS

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

The desktop installer is available for Apple Silicon Macs. CLI installation is also supported.

Linux

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

WSL2 and Android through Termux also have documented installation paths.

Official instructions: Open Hermes documentation ↗

First time setup

  1. Run hermes setup for the setup wizard.
  2. Use hermes model to choose or configure a provider.
  3. Use hermes tools to configure available tools.
  4. For the Nous Portal path, hermes setup --portal provides a guided login and tool setup.

Run in a project folder

  1. Open a terminal in the project directory.
  2. Run hermes to start chatting.
  3. Ask for a read only overview before allowing edits.
Good first task: Get one clean conversation working before adding gateways, scheduled jobs, skills, or other advanced features.

Common errors and fixes

hermes not found

Reload your shell and check the official install path.

Provider missing

Run hermes model or hermes setup and configure a supported provider.

Tools unavailable

Run hermes tools and check the provider or tool configuration.

Unexpected changes

Stop the task and review the enabled tools, project scope, and terminal configuration.

Tips for best results

  • Treat tools as explicit capabilities.
  • Start with one working conversation.
  • Use small tasks.
  • Verify checks.
  • Protect credentials.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow up.
