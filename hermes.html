Hermes Agent

A terminal assistant with coding tools, provider choices, skills, and integrations. Configure file and terminal access deliberately.

Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.

What it is and what it does

A terminal assistant with coding tools, provider choices, skills, and integrations. Configure file and terminal access deliberately. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

Choose your operating system. Follow the official source if an install command changes.

Windows

Native PowerShell CLI installer or official desktop installer.

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

Official CLI shell installer; check platform notes.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

Official CLI shell installer.

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Official instructions: Open Nous Research documentation ↗

First-time setup

  1. Run hermes setup (optionally hermes setup --portal)
  2. use hermes model for provider setup
  3. inspect hermes tools and enable only needed capabilities.

Run in a project folder

  1. Open terminal in project directory
  2. run hermes or hermes chat -q "your question"
  3. ask for read-only overview before edits.
Good first task: Ask for a read-only project overview before requesting edits.

Common errors and fixes

hermes not found

reopen terminal; check official PATH notes.

Provider missing

run hermes model or setup; protect credentials.

Tools unavailable

inspect hermes tools and provider needs.

Unexpected changes

stop and review tool/terminal config.

Tips for best results

  • Treat tools as explicit capabilities
  • plan first
  • use small tasks
  • verify checks
  • protect keys.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow-up.
