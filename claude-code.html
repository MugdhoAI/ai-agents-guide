Anthropic · PRACTICAL GUIDE

Claude Code

Anthropic’s terminal coding agent reads project context, edits files, and runs development commands through permission-controlled tools.

Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.

What it is and what it does

Anthropic’s terminal coding agent reads project context, edits files, and runs development commands through permission-controlled tools. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

Choose your operating system. Follow the official source if an install command changes.

Windows

Use WSL or native Windows with Git for Windows/Git Bash; install Node.js 18+ first.

npm install -g @anthropic-ai/claude-code

Mac

Install Node.js 18+ and npm. Avoid sudo for global npm installs.

npm install -g @anthropic-ai/claude-code

Linux

Install Node.js 18+ and npm using your distribution’s supported method.

npm install -g @anthropic-ai/claude-code

Official instructions: Open Anthropic documentation ↗

First-time setup

  1. Run claude and complete sign-in
  2. use CLAUDE.md for concise project instructions
  3. keep permission prompts enabled
  4. run claude doctor to check setup.

Run in a project folder

  1. Change to your project folder and run claude
  2. it uses the current directory. Ask for an explanation and plan before edits.
Good first task: Ask for a read-only project overview before requesting edits.

Copy-ready prompts

Replace bracketed details with your goal, constraints, or error message.

01 · Explore

Explain this codebase and request flow. Do not edit.

02 · Debug

Trace [bug], explain the fix, then implement.

03 · Build

Build [feature] minimally; ask before dependencies.

04 · Review

Review my diff for correctness/security. Do not edit.

05 · Test

Add focused tests for [behavior] and run them.

06 · Refine

Diagnose [command] failing with [error].

07 · Diagnose

Improve [area] while preserving successful behavior.

08 · Document

Update [docs] to reflect verified implementation.

Common errors and fixes

claude not found

restart terminal; check npm PATH.

Windows shell issue

use WSL/Git Bash; set CLAUDE_CODE_GIT_BASH_PATH if needed.

Auth failure

finish browser sign-in and check access.

Permission interruptions

narrow task, keep approvals enabled.

Tips for best results

  • Keep CLAUDE.md focused
  • inspect first
  • use checkpoints
  • state tests
  • never paste secrets.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow-up.
