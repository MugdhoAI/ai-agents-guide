Claude Code

Anthropic’s coding agent works in the terminal and desktop app, with support for macOS, Windows, Linux, and WSL.

Before you start
Use a trusted project, back up your work, and review changes and commands before accepting them.
Where Freebuff fits
Freebuff is a separate free AI coding platform. It does not make Claude Code free. Freebuff Desktop can run a locally installed Claude Code setup when you already have the required provider access.

What it is and what it does

Claude Code reads project context, edits files, runs development commands, and uses tools through permission controls. It can run natively on supported Windows systems or inside WSL. Treat it as a collaborator that needs context and supervision; verify changes before relying on them.

Install

The native installer is the recommended path. Homebrew and npm are also supported.

Windows

irm https://claude.ai/install.ps1 | iex

PowerShell native install. Git for Windows is optional and enables the Bash tool.

macOS

curl -fsSL https://claude.ai/install.sh | bash

Native installer. Homebrew is also supported.

Linux

curl -fsSL https://claude.ai/install.sh | bash

Native installer. Additional package methods are documented by Anthropic.

Official instructions: Open Claude Code documentation ↗

First time setup

  1. Run claude and complete sign in.
  2. Use CLAUDE.md for concise project instructions.
  3. Keep permission controls enabled and review requests.
  4. Run claude doctor when you need installation or configuration diagnostics.
Access: Claude Code is available through eligible Pro, Max, Team, and Enterprise plans, or through Anthropic Console API access and supported cloud providers. The free Claude plan does not include Claude Code.

Run in a project folder

  1. Change to your project folder.
  2. Run claude.
  3. Ask for an explanation and plan before making broad edits.
Good first task: Ask for a read only project overview before requesting edits.

Copy ready prompts

Replace bracketed details with your goal, constraints, or error message.

01 · Explore

Explain this codebase and request flow. Do not edit.

02 · Debug

Trace [bug], explain the cause, then implement the smallest fix.

03 · Build

Build [feature] using the existing architecture. Ask before dependencies.

04 · Review

Review my diff for correctness and security. Do not edit.

05 · Test

Add focused tests for [behavior] and run them.

06 · Refine

Improve [area] while preserving successful behavior.

07 · Diagnose

Diagnose [command] failing with [error].

08 · Document

Update [docs] to reflect verified implementation.

Common errors and fixes

claude not found

Restart the terminal and check the installer path.

Windows shell issue

Native Windows can use PowerShell. Install Git for Windows if you want the Bash tool.

Auth failure

Run claude again and complete browser sign in, or check your configured API provider.

Permission interruptions

Narrow the task and review each requested capability before approving it.

Tips for best results

  • Keep CLAUDE.md focused.
  • Inspect first.
  • Use checkpoints.
  • State the tests that matter.
  • Never paste secrets.
Review loop: Describe task → inspect plan → review diff → run checks → focused follow up.
